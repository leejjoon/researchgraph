# HTTP, SSE and viewer boundary
1. Given the installed optional HTTP server and either cache mode. When every operation scenario (including init/import/export) runs through its adapter. Then results match API/installed CLI/MCP JSON, RuleViolation is 422 and project-open errors are 503. The launch actor is fixed (serving Git human by default, explicitly declared agent when selected; decision 022), roles are declared per request and read-only cannot be disabled. Current graph responses carry the associated snapshot cursor in X-Researchgraph-Cursor, not a later observation; historical reads do not claim a live cursor.
2. Given a launch fragment token. When the host removes the fragment and exchanges it once by JSON POST session. Then it receives a host-only HttpOnly SameSite Strict cookie valid for that instance. Reuse, prior-instance credentials and query tokens fail; protected operations/profile/events/artifact routes require the cookie. Root/bootstrap does not reveal graph state unauthenticated.
3. Given any protected route. When authentication is missing or Host/Origin is foreign. Then 403 with no state disclosure/mutation. Session exchange and writes require matching Origin; same-host authenticated reads may omit it. Responses have no-store/no-referrer and credentials never appear in logs, referrers, DOM attributes or persistent storage.
4. Given an artifact registered to node A. When its existing regular file is downloaded. Then it is an octet-stream attachment with nosniff and a safe encoded basename. Unregistered files, wrong-node paths, absolute/plain/encoded/double-encoded traversal, escaping symlinks and a swap after validation return nondisclosing 404. Containment remains held through opening. Attached hostile HTML/SVG does not execute in the serving origin.
5. Given a retained SSE cursor. When Last-Event-ID resumes it. Then only successors arrive and every id is the full identical cursor. Expired, malformed or previous-generation ids reset; snapshot/subscription races and slow consumers recover to a fresh load. Keepalive comments occur at fifteen seconds; disconnect/shutdown closes resources without unbounded buffers.
6. Given fifty running nodes. When twenty actual external CLI writes occur. Then each reaches SSE within three seconds. Subsequent browser load checks each write-to-DOM latency too, with all samples and claim file growth reported; no deadline relaxation or substituted operations.
7. Given a custom profile with unused declared types, conditions and roles. When the authenticated viewer bootstraps. Then shared profile metadata drives its columns/gates/roles/claimability without discipline knowledge or callable exposure. Two component instances remain independent. Assets come from the actual installed wheel and help works without extras.
8. Given a valid Hypothesis-derived-from-Prediction/tests-back cycle, retired edges and an invalid hand-built I1 cycle. When ranked using only non-retired I1 constraints with created/id fallback and collapse after ranking. Then every node renders and is selectable; non-ranking edges do not hang or drop records. No layout file is created.
9. Given inspector/review actions, hostile node text and an injected write failure. When an action runs. Then text is escaped, errors are displayed and persisted state refetched without retry. Validation/rollback creates no replacement; retained-byte commit/hook failure displays the actual persisted replacement and optional Instruction. Approved Hypothesis and failed-Task re-run history are verified by installed CLI.
10. Given conditional/multi-gate queue entries. When a permitted reviewer approves the oldest. Then queue/badge equal installed queue, partial approvals remain queued and only full activation removes an item. Wrong-role, human-only, concurrent review and read-only refusals never show optimistic success. Send back is reject-with-reason.
11. Given monitoring data with overlapping subtrees, expired leases and remaining statuses. When refreshed by deltas/index/reset/clock/reconnect. Then counts match installed digest/stale/ready/running, subtree members count distinctly, disconnected/stale indicators are truthful, and a fresh load agrees. No runner capacity or inherited budget/lease promises appear.
