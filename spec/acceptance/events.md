# Observed-state events
1. Given a first graph and its observation cursor. When random valid operations change nodes/edges and the consumer folds deltas (refetching on reset). Then its state equals the current graph in both cache modes. No event file is written.
2. Given an independent Project or external installed CLI writer. When it writes, including with no-commit or twice in one second, and even if another reader already refreshed the cache. Then the observer reports the persisted changes. HEAD-only changes cause an index notification, not fabricated node changes.
3. Given a validation refusal or injected rename failure whose writes fully roll back. When observed. Then there are no domain changes. Given injected commit failure retaining bytes or a post-commit hook failure. Then the observer and a second Project converge on the retained bytes despite the reported operation error.
4. Given a running claim whose lease expires with no file change. When the observation clock reaches expiry. Then an index event causes ready/running/digest to refresh; node bytes and stored running status remain unchanged.
5. Given a retained full cursor. When changes are requested since it. Then only its successors are returned with the exact same opaque `v1:<generation>:<seq>` representation in Python, CLI and SSE. Malformed, unknown/future or expired cursors instead yield one index reset.
6. Given a restarted ChangeSource and an old cursor whose sequence overlaps the new source. When source bytes are unchanged. Then its random independent generation still differs, the old cursor resets and no old-generation replay is claimed.
7. Given index deletion or rebuild with unchanged source state. When observed. Then state equality holds without fabricated domain events. Cursor/generation/time identity across independent observers is not required.
8. Given a record disappears externally. When observed. Then reset requires a fresh snapshot instead of an unrepresentable deletion delta. A consumer that falls behind bounded retention also resets; memory stays bounded and disconnect releases owners.
9. Given a write races snapshot/subscription. When the client catches up from the snapshot's associated cursor or resets and refetches. Then it converges to a fresh graph. Coalescing may omit intermediate observations, never final persisted state. Envelope at and HEAD are observations, not causal provenance.
10. Given installed events follow with fifty running nodes and twenty actual external claim writes on valid ready or expired-reclaimable targets. When each write is observed. Then each latency is below three seconds, all twenty samples and claim file growth are reported, and follow exits zero on stdin close or SIGINT. JSONL is one envelope per line; human output one line per envelope. Read-only uses no writer lock.
