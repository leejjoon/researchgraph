# import
1. Given an archive from `export`. When alice imports it into an empty directory. Then the directory is an initialised project pinning the archive's profile, `graph/` and `.researchgraph/history.jsonl` are present, and there is one commit `rg: import`.
2. When alice imports into a non-empty directory. Then RuleViolation `not_empty`.
3. When the archive is not a researchgraph export. Then RuleViolation `bad_archive`.
4. When the archive pins a profile version newer than installed. Then RuleViolation `profile_too_new`.
5. Given an imported project whose archive recorded T1 `active` with an open interval. When agent1 claims T1 (once with `--commit`, once with `--no-commit`). Then in both cases `status_intervals` has exactly one open interval for T1 (`running`), the archived `active` interval is closed at the claim commit (or at `(null, now)` for `--no-commit`), `--as-of <before the claim>` reports `active`, and the rows are identical after `rm index.sqlite`.
6. Given a valid archive whose latest restored timestamp is `2026-10-19T10:00:00Z`. When alice imports with `now = 2026-10-19T09:00:00Z`. Then RuleViolation `clock_skew`, the destination remains absent or empty as it was, and no commit is created.
7. Given an archive whose latest restored timestamp is `2026-10-19T10:00:00Z`. When alice imports with that exact `now`, then agent1 claims an archived active Task at `2026-10-19T10:01:00Z` (once with `--commit`, once with `--no-commit`). Then import and claim succeed, archived timestamps are unchanged, every closed interval has `to_time >= from_time`, and historical queries agree before and after index deletion.
8. Given valid archives where the latest restored timestamp occurs in turn in a node's `created`, `updated`, approval `at`, artifact `added_at`, lease `acquired_at` or `expires_at`, an edge's `created` or `retired_at`, or a history interval's `from_time` or `to_time`. When importing before that timestamp. Then `clock_skew` in every case; null timestamps do not contribute to the floor. A future lease expiry therefore requires an import `now` at or after that expiry.
