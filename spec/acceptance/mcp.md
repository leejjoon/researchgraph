Then names and schemas equal the graph registry plus declared execution context and readOnlyHint matches each kind; instructions equal profile guidance only. Every operation scenario runs through MCP with kept/deleted cache and CLI-equivalent JSON/errors.
2. Given an agent launch with fixed role. When a tool supplies actor, role, read-only or project overrides. Then it cannot gain authority or change the selected project. Missing agent identity without explicit human mode refuses launch. Human-only gates and wrong-role refusals remain core results.
3. Given read-only full or essential preset. When listing tools and attempting any hidden write including init/import. Then writes are absent and refused server-side without filesystem changes. Essential contains exactly the sixteen approved tools before read-only intersection; full is default.
4. Given any successful operation. When its result is received. Then JSON text and structuredContent preserve CLI-equivalent data, including omission/null and repeated arguments. A RuleViolation returns isError and structured rule/message/ids without stdout logging contamination.
5. Given random permitted operation sequences through MCP. When writes succeed or fail. Then I1–I8 hold, including permission and cache parity. No adapter revalidation or SQL path bypasses shared operations.
6. Given real installed stdio transport. When current discovery initialization, digest, cancellation and shutdown occur. Then protocol framing is valid, stdout has no logging, and request/process owners close. A legacy initialize-only connection is explicitly refused for tools rather than returning wrapped arrays or partial successes. Core-only import/help remain usable without the extra; invoking MCP without it reports the missing-extra remedy.
7. Given human-seeded approved prerequisites. When the ten-step deterministic agent session replays through MCP. Then an independent checker proves the final graph and no human writes after seed or bypassed gates. This is not either required real unassisted Claude Code/Codex CLI recording; those require actual product/model/configuration, consent-safe transcripts and checker output.
