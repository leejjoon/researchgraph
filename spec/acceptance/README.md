# Acceptance scenarios
One file per operation (`attach.md`, `link.md`, `init.md`, `import.md` included, plus `notes-and-pins.md` for the relation edges, `queries.md`, and `general.md` for rules every write shares). Each scenario is Given / When / Then and maps to at least one test in `tests/`. "the research profile" means a fresh `rg init --profile research` project with one commit. Actors: `alice` (human, declares role `owner`), `bob` (human, declares role `reviewer`), `agent1` and `agent2` (agents). Tests fix `now` (`--now`) so lease and interval arithmetic is deterministic. Every scenario must also pass with the index deleted before the When step, and through the CLI as well as the Python API (T15).
