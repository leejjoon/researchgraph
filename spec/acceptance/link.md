# link
1. Given tasks A and B active. When agent1 links `blocks A → B`. Then an edge file exists with author agent1, `show B` reports blocked, and the commit message starts with `rg: link ed-`.
2. Given tasks A and B with `blocks A → B`. When agent1 links `blocks B → A`. Then RuleViolation `cycle`.
3. When agent1 links `answers` from a Task to a Question. Then RuleViolation `edge_endpoints`.
4. When agent1 links `blocks` with `fields: {x: 1}`. Then RuleViolation `schema` (no fields allowed on `blocks`).
5. Given `blocks A → B` already exists and is not retired. When anyone links `blocks A → B` again. Then RuleViolation `duplicate_edge`.
6. When anyone links `supersedes`, `explains` or `instructs`. Then RuleViolation `reserved_edge_type`.
7. Given Claim C1 proposed and Result R1. When alice links `cites C1 → R1`. Then `evidence C1` lists R1 and C1 can now be approved.
8. Given a profile adding `(Claim, Literature)` to `cites` while retaining `(Claim, Result)` and `(Claim, Reference)`, and existing Claim C and Literature L. When alice links `cites C → L`. Then it succeeds and evidence traverses L identically to any other permitted target. A different source or undeclared endpoint type is refused with `edge_endpoints`.
9. Given a profile redeclaring cites with a missing core pair, a wildcard source or target, or a source other than Claim. When the profile loads. Then `schema`. Changing another core edge's endpoint pairs also raises `schema`; adding a citation target does not relax other edges.
10. Given existing immutable Reference nodes and citation edges. When a profile adds Literature as a permitted target. Then those existing records remain valid, unchanged, and traversable; no Reference is renamed or rewritten.
11. Given a profile declaring Claim and Literature but neither Result nor Reference, with `cites` retaining both core pairs and adding Literature. When C cites L and L derives from input I. Then evidence C includes L and I. When I is superseded, stale reports C with the replacement head and weakest C ranks L as having a superseded input. No absent Result/Reference vocabulary disables these queries.
12. Given that profile and several direct non-retired Literature citation targets. When weakest is read. Then all targets rank by superseded input, integer runs (missing means 0), boolean held_out (missing means false), then id. Equal scores break by id; retired citation edges are ignored. Invalid scoring writes (`runs: true`, string runs, fractional runs, string or numeric held_out) raise `schema` rather than being coerced. Query defaults do not add stored fields.
