# v0.1 work list (ordered)

Each item: what to build, and **done when**. One commit per item, message prefixed with the id.

- **T01 Package skeleton.** `pyproject.toml`, `src/researchgraph/`, `pytest` + `hypothesis` + `ruff` configured, `rg --version`. Done when `pip install -e . && rg --version` works, `ruff check` passes, and `pytest` runs zero tests green.
- **T02 Canonical YAML I/O.** `store/io.py`: load/dump nodes and edges (including edge `fields`) in the canonical form of `spec/store-layout.md`; fixtures under `tests/fixtures/canonical/` for every rule (quoting, block strings, null/empty, key order, timestamps); round-trip property test. Done when dump(load(x)) == x for 1,000 generated nodes, every fixture round-trips byte for byte, and a no-op rewrite yields no git diff.
- **T03 Data model types.** `model.py`: Node, Edge, Actor, Approval, Artifact, Lease, Write, RuleViolation; status enum; immutable-key set; `inherit` enum. Done when hypothesis strategies exist for all of them in `tests/strategies.py`.
- **T04 Profile contract and bundled profiles.** `profiles/base.py`, `profiles/research.py`, `profiles/tasks.py`, entry-point discovery, schema closing (`additionalProperties: false`), default materialisation, gate loading (`unsupported_gate_transition`). Done when `Profile.load("research")` and `Profile.load("tasks")` return the types in `spec/profiles.md` and schema validation of node and edge `fields` works, including defaults.
- **T05 Project store and `init`.** `rg init`; file layout; lock file; atomic multi-file write with rollback; commit helper with the actor as author. Done when `spec/acceptance/init.md` and `general.md` 5 pass, and a node written through the store loads back identically.
- **T06 Index.** SQLite schema, rebuild from files, content-hash staleness check, `status_intervals` from git log unioned with `history.jsonl`, `ready` view taking `now`. Done when rebuild of a 20k-node synthetic project < 5 s (excluding the git walk) and `general.md` 8's I8 half passes for a store with hand-written files.
- **T07 Validators.** I1–I7 as functions over a `Write`; profile validators hooked in; the shared rules in `spec/operations.md` (`not_found`, `read_only`, `profile_too_new`, `human_only_approval`, `wrong_role`, `unsupported_by_profile`). Done when unit tests cover every invariant with hand-built writes and `general.md` 3 passes; the random-sequence property test is T11's done-when.
- **T08 Derived queries.** ready (order), blocked, queue, history, evidence, stale, weakest, alternatives, predictions, matrix, notes, subtree, since, where (all filters), digest, show (incident edges, instructions, pins, flags, warnings), all over stores built from `tests/strategies.py` through the T05 store. Done when `spec/acceptance/queries.md` 1–5 and 7–14 pass against hand-built stores (they are re-run against operation-built stores as each operation lands).
- **T09 propose, link, approve, reject.** Done when `spec/acceptance/{propose,link,approve,reject}.md` and `general.md` 1, 2, 7 all pass.
- **T10 supersede, instruct, retire.** Done when their acceptance files pass, including per-type edge inheritance (`supersede.md` 9–13) and I3.
- **T11 claim, renew, release, complete, fail.** Done when their acceptance files pass, including expired-lease reclaim, never-shortening renewal, additive usage, artifact path rules, and `general.md` 6 and 8 (random operation sequences never violate I1–I8).
- **T12 status_intervals and --as-of.** Done when `queries.md` 6 passes and a scrub over 200 commits of a 5k-node project takes < 2 s total.
- **T13 expand, budget, tag, attach; relation edges.** Done when `expand`, `budget`, `tag`, `attach` and `notes-and-pins` acceptance files pass; subtree-based budget exclusion works with the inclusive comparison.
- **T14 export/import.** Done when `export.md`, `import.md` and `general.md` 4 pass, including byte-identical repeated export and the `--since` endpoint closure.
- **T15 CLI completeness.** Every op and query as `rg` subcommands with `--json`, `--read-only`, `--as-agent`, `--role`, `--now`, `--commit/--no-commit`, JSON-encoded structured arguments, exit codes per spec. Done when the whole acceptance suite runs through the CLI (subprocess) as well as the Python API.
- **T16 Reference runner example.** `examples/minimal_runner.py` against the `tasks` profile: poll ready, claim, run `fields.command` in a shell, complete with files under `artifacts/<id>/` or fail with the exit code; skip Tasks without a command. Done when a three-task chain runs to completion unattended and a failing task produces one Failure node and no loop.
- **T17 Quickstart and API docs.** `docs/quickstart.md` under 30 lines; docstrings on every public call. Done when a new reader can reproduce T16 from the quickstart alone.
- **T18 CI.** GitHub Actions: `ruff`, tests twice (index kept / index deleted), synthetic-scale benchmark, acceptance via CLI. Done when all green on a clean clone.

Gate 1 (end of v0.1): T01–T18 done; astroharness profile drafted against the API in a separate repository with no change to the core.
