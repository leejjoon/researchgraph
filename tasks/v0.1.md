# v0.1 work list (ordered)

Each item: what to build, and **done when**. One commit per item, message prefixed with the id.

- **T01 Package skeleton.** `pyproject.toml`, `src/researchgraph/`, `pytest` + `hypothesis` configured, `rg --version`. Done when `pip install -e . && rg --version` works and `pytest` runs zero tests green.
- **T02 Canonical YAML I/O.** `store/io.py`: load/dump nodes and edges (including edge `fields`) with fixed key order; round-trip property test. Done when dump(load(x)) == x for 1,000 generated nodes and a no-op rewrite yields no git diff.
- **T03 Data model types.** `model.py`: Node, Edge, Actor, Approval, Artifact, Lease, RuleViolation; status enum; immutable-key set. Done when hypothesis strategies exist for all of them in `tests/strategies.py`.
- **T04 Profile contract and bundled profiles.** `profiles/base.py`, `profiles/research.py`, `profiles/tasks.py`, entry-point discovery. Done when `Profile.load("research")` returns the types in `spec/profiles.md` and schema validation of `fields` works.
- **T05 Project store.** `rg init`; file layout; atomic write; commit helper. Done when acceptance `propose` 1 passes without an index.
- **T06 Index.** SQLite schema, rebuild from files, tree-hash staleness check, `ready` view. Done when rebuild of a 20k-node synthetic project < 5 s and I8 property test passes (query results equal before/after `rm index`).
- **T07 Validators.** I1–I7 as functions; profile validators hooked in. Done when random operation sequences from `tests/strategies.py` never leave the store violating any invariant.
- **T08 propose, approve, reject.** Done when `spec/acceptance/{propose,approve,reject}.md` all pass.
- **T09 supersede, instruct, retire.** Done when their acceptance files pass, including edge inheritance and I3.
- **T10 claim, renew, release, complete, fail.** Done when their acceptance files pass, including expired-lease reclaim, renewal, usage recording and artifact hashing.
- **T11 Derived queries.** ready (priority order), blocked, queue, history, evidence, stale, weakest, alternatives, predictions, matrix, notes, subtree, since, where (incl. --tag, --text), digest. Done when `spec/acceptance/queries.md` 1–5, 7 pass.
- **T12 status_intervals and --as-of.** Done when queries 6 passes and a scrub over 200 commits of a 5k-node project takes < 2 s total.
- **T13 expand, budget, tag; relation edges.** Done when `expand`, `budget`, `tag` and `notes-and-pins` acceptance files pass; subtree-based budget exclusion works.
- **T14 export/import.** Done when acceptance `export` passes byte-for-byte.
- **T15 CLI completeness.** Every op and query as `rg` subcommands with `--json`, `--read-only`, `--as-agent`, `--commit/--no-commit`, exit codes per spec. Done when the acceptance suite runs through the CLI (subprocess) as well as the Python API.
- **T16 Reference runner example.** `examples/minimal_runner.py`: poll ready, claim, run `fields.command` in a shell, complete or fail. Done when a three-task chain runs to completion unattended.
- **T17 Quickstart and API docs.** `docs/quickstart.md` under 30 lines; docstrings on every public call. Done when a new reader can reproduce T16 from the quickstart alone.
- **T18 CI.** GitHub Actions: lint, tests twice (index kept / index deleted), synthetic-scale benchmark, acceptance via CLI. Done when all green on a clean clone.

Gate 1 (end of v0.1): T01–T18 done; astroharness profile drafted against the API in a separate repository with no change to the core.
